::selection { background-color · color }

Označ tenhle odstavec myší. Zvýraznění včetně tučného slova nese brand token z tématu.

Klikni do textového inputu — caret-color je vidět jen při focusu. Poslední dvojici odstavců označ tažením myši, jinak ::selection nic neukáže. Přepni téma: všechny tři barvy vedou na light-dark() tokeny, takže se otočí s ním.

accent-color

/* Dědičná — jedna deklarace na obalu
   obarví všech pět prvků uvnitř. */
:root { --uc-accent: var(--text-brand-primary); }

.uc-accent {
  accent-color: var(--uc-accent);
}

caret-color

/* obarví jen kurzor, ne text ani rámeček */
.uc-caret {
  caret-color: var(--text-brand-primary);
}

/* Outline leží mimo box, layout se nehne */
.uc-caret:focus-visible {
  outline: 2px solid var(--text-brand-primary);
  outline-offset: 2px;
}

::selection

/* dědí se vlastním highlight řetězem;
   druhý selektor pokryje i potomky */
.uc-selection::selection,
.uc-selection ::selection {
  background-color: var(--surface-brand-primary-strong);
  color: var(--text-primary-on-surface-brand-primary-strong);
}
