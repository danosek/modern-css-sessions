S2 – Colors & Typography

light-dark()

Jeden token, dvě hodnoty. Přepínačem je color-scheme.

light-dark()
light-dark(<světlá hodnota>, <tmavá hodnota>)
použije se při color-scheme: light použije se při color-scheme: dark zvýrazněný argument je ten, který právě platí
  1. 1 · privátní hodnoty
    --_text-dixie_light: oklch(59.2% 0.152 71); --_text-dixie_dark: oklch(73% 0.13 71);

    Dvě konstanty vedle sebe. Ani jedna o tématu neví — jsou to jen dvě čísla v paletě.

  2. 2 · globální token
    --text-dixie: light-dark(var(--_text-dixie_light), var(--_text-dixie_dark));

    Jediné patro celého řetězu, které se ptá na téma. Vrstva pod ním ani nad ním nemá žádnou větev.

  3. 3 · sémantický token
    --text-brand-primary: var(--text-dixie);

    Ptá se na roli, ne na barvu. O tématu neví nic, a proto ho výměna témat nikdy nenutí měnit.

Tři různé tokeny, tentýž mechanismus: privátní dvojice → light-dark(). Sémantickou vrstvu nad sebou má z nich jen ten první. V CSS pod nimi se nemění ani písmeno — mění se jen to, co z light-dark() vypadne.

--text-brand-primary
--text-blue
--surface-base
Přepínač vpravo nahoře nepřebarvuje nic ručně — jen sáhne na data-theme dokumentu, čímž se přepne color-scheme. Z něj light-dark() čte, který argument vrátit.

Spectro — tři vrstvy jednoho tokenu

/* shared/spectro-theme.css */
:root {
  /* 1 · privátní hodnoty — o tématu nevědí */
  --_text-dixie_light: oklch(59.2% 0.152 71);
  --_text-dixie_dark: oklch(73% 0.13 71);

  /* 2 · tady a jenom tady padne rozhodnutí */
  --text-dixie: light-dark(var(--_text-dixie_light), var(--_text-dixie_dark));

  /* 3 · sémantický token — ptá se na roli */
  --text-brand-primary: var(--text-dixie);
}

Demo — zvýraznění aktivního argumentu

/* Který argument svítí, neřeší JS —
   je to zase light-dark(). */
.ld-anatomy__arg--light {
  background: light-dark(var(--surface-brand-primary-strong), transparent);
  color: light-dark(var(--text-primary-on-surface-brand-primary-strong), var(--text-secondary));
}

.ld-anatomy__arg--dark {
  background: light-dark(transparent, var(--surface-brand-primary-strong));
  color: light-dark(var(--text-secondary), var(--text-primary-on-surface-brand-primary-strong));
}
