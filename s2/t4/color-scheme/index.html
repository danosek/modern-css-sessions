color-scheme

Bez color-scheme uvízne light-dark() ve světlé větvi.

color-scheme·light-dark()
color-scheme: normal | light | dark | light dark
  • větev, kterou vybere light-dark() — tedy i každý sémantický token Spectra
  • skin, kterým prohlížeč kreslí vlastní UI: scrollbary, formulářové prvky, výchozí canvas

normal je výchozí hodnota, tedy přesně stav „bez color-scheme“: použité schéma je světlé. Nic se nerozbije — light-dark() jen natrvalo vrací první argument a nativní prvky zůstanou světlé. Tmavá větev se tiše ignoruje, a to je na tom to zákeřné.

Proč Spectro nemá @media (prefers-color-scheme)

Téma se přepíná atributem data-theme, ne médiem — uživatel si ho volí tlačítkem, komponenta může mít téma napevno nebo obrácené a v spectro-theme.css to ušetří druhou sadu deklarací. O to nutnější je color-scheme: bez něj je použité schéma light, takže light-dark() vždycky vrátí první argument a nativní prvky zůstanou světlé. Přepínač témat by pak přepínal jen to, co si stránka kreslí sama.

Přepni téma stránky tlačítkem vpravo nahoře: okolí panelů se převrátí, panely ne — každý si color-scheme drží sám. Třetí panel se řídí nastavením operačního systému, ne stránkou. Nejlíp je zásah prohlížeče vidět na formulářových prvcích — checkboxu, rangi, selectu, poli i progressu. Projeď kolečkem obsah v rámečku dole: scrollbar má barvu podle schématu svého panelu. Na macOS je ale scrollbar překryvný, takže se ukáže až během scrollování a pak zase zmizí.

Tři panely, tři schémata

/* Dědičná vlastnost — platí i pro
   nativní prvky uvnitř panelu. */
.cs-panel--light { color-scheme: light; }
.cs-panel--dark  { color-scheme: dark; }

/* Dvě hodnoty: vybírá operační systém. */
.cs-panel--auto  { color-scheme: light dark; }

Co z color-scheme čte barva

/* Paletové tokeny theme-aware nejsou —
   větev vybere light-dark() podle panelu. */
.cs-swatch {
  background: light-dark(var(--dixie-20), var(--dixie-90));
  color: light-dark(var(--dixie-100), var(--dixie-10));
}

/* Sémantické tokeny Spectra to mají uvnitř:
   --surface-front: light-dark(var(--_surface-front_light),
                               var(--_surface-front_dark)); */
.cs-panel {
  background: var(--surface-front);
  color: var(--text-primary);
  border: 2px solid var(--border-strong);
}
