Zruš half-leading a label tlačítka sedne doprostřed.

text-box-trim·text-box-edge

Odkud se ta mezera bere

Řádkování větší než 1 rozdělí přebytek na dvě poloviny a přilepí je nad text a pod něj. Ta půlmezera je součástí boxu, takže padding na obou stranách stejný nedá opticky stejný odstup.

text-box-trim Které strany odříznout: trim-start, trim-end, trim-both, none. text-box-edge Odkud se měří. Nahoře cap (výška verzálek) nebo ex (x-height), dole alphabetic (účaří) nebo text. Obě hodnoty jsou povinné — text-box-edge: cap je neplatné a prohlížeč celou deklaraci tiše zahodí. Ověřeno: CSS.supports vrací false pro cap a true pro cap text. text-box Zkratka za obojí: text-box: trim-both cap alphabetic. Tenhle zápis budeš používat.

Táž slova, tři výšky boxu

Všechny tři mají font-size: 22px a line-height: 2, tedy 44 px na řádek. Pozadí je obtažené kolem boxu, aby bylo vidět, co je text a co mezera. Výšku měří skript z vykresleného prvku.

Proč to řešit — tlačítko

Obě tlačítka mají shodný padding. Vlevo půlmezera nadzvedne text nad optický střed, takže dole vypadá odstup větší. Vpravo je box odříznutý na písmo a padding tak sedí na tom, co je vidět.

Pozor na jednu věc: po odříznutí musíš dorovnat padding, protože prvek najednou zabírá o půlmezeru méně. Trim není náhrada za odstupy, je to jen posun toho, od čeho se odstupy měří.

Odříznutí a detekce

/* Odřízne půlmezeru z obou stran a měří
   ji od výšky verzálek po účaří. */
.tb-box--trim {
  text-box: trim-both cap alphabetic;
}
