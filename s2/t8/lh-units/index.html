S2 – Colors & Typography

lh · rlh

Rozestupy odvozené od řádkování, ne od magických pixelů.

lh·rlh

Jedna jednotka = jeden řádek

Odstup zapsaný v pixelech o textu nic neví. Zvětšíš písmo a padding zůstane, kde byl — rytmus se rozjede. lh je jednotka, která tenhle problém řeší: 1lh je výška jednoho řádku. Když má text velikost 13 px a line-height: 1.6, je 1lh rovno 20,8 px. Změní-li se kterékoli z těch dvou čísel, změní se i odstup.

1lh Výška řádku tohoto prvku. Každý prvek může mít jinou, protože každý může mít jiné line-height. 1rlh Výška řádku v <html>. Stejná na celé stránce, ať je uvnitř jakékoli písmo — jako rem u velikostí. --base-3 Spacing token Spectra, tady 24 px. Drží mřížku, ale o písmu neví nic — po změně řádkování zůstane, kde byl.

Změň řádkování a sleduj odstupy

Slider mění line-height všech tří sloupců zároveň. Sleduj, který padding se hýbe s ním: vlevo lh, uprostřed rlh, vpravo spacing token.

Kdy co: lh ber tam, kde má odstup patřit k textu — padding textového bloku, mezera mezi odstavci, výška řádku v seznamu. Rytmus pak vydrží změnu velikosti písma i řádkování, protože se od nich odvozuje.

Spacing tokeny Spectra ber tam, kde odstup patří k layoutu — gap v mřížce, padding panelu, odsazení sekcí. Ty mají držet mřížku napříč celou aplikací a nemají se hýbat podle toho, jaké písmo je zrovna uvnitř. Míchat obojí v jednom prvku je nejrychlejší cesta k rozsypanému rytmu.

Tři způsoby téhož odstupu

/* 1lh je řádkování TOHOTO prvku. */
.lh-card--lh {
  padding-block: 1lh;
  margin-block-end: 1lh;
}

/* 1rlh je výška řádku v . */
.lh-card--rlh {
  padding-block: 1rlh;
  margin-block-end: 1rlh;
}

/* Spacing token — o písmu neví nic. */
.lh-card--token {
  padding-block: var(--base-3);
  margin-block-end: var(--base-3);
}
