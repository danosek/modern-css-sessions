oklch() vs hsl()

Tři zápisy téže barvy. Počítat jde jen s jedním.

oklch()·hsl()

Jedna barva, tři zápisy

Vyber jakoukoli barvu. Všechny tři zápisy pod tím popisují tutéž barvu — liší se jedině tím, kolik se z nich dá vyčíst a co s nimi jde spočítat. Posledním řádkem je odpověď na nejběžnější úkol v design systému: zesvětli ji o deset bodů.

hex

Tři bajty kanálů. O jasu ani odstínu neříká nic — jsou to souřadnice, se kterými se nepočítá.

zesvětlit o 10? nejde zapsat
hsl

Odstín, sytost, světlost. Čitelné a spočítatelné — ale to poslední číslo neodpovídá tomu, jak barvu vidíme.

oklch

Lightness, chroma, hue. L je perceptuální: 70 % znamená stejný jas u žluté jako u modré.

Klikni na tu poslední řádku u obou zápisů a porovnej vzorky. V hsl zesvětlení o deset bodů často změní i vnímanou sytost, v oklch drží chroma i hue a mění se jedině jas.

Hue je úhel

L a C jsou úsečky s koncem. H je kruh — 0 a 360 je totéž místo, -30 je totéž co 330 a 400 totéž co 40. Prohlížeč si to zabalí sám, takže calc(h + 180) pro komplement nemusíš normalizovat. Přijímá i jednotky: deg, turn, rad, grad.

0 90 180 270

Jenom ta nula nezačíná v obou zápisech na stejném místě. Tohle je nejčastější překvapení při převodu palety — čísla se přenesou, odstíny ne.

hsl(0 70% 50%) v oklch je to hue
oklch(65% 0.13 0) hue 0 — jiná barva

Chroma nemá pevný strop

L a H mají pevný rozsah — 0 až 100 % a 0 až 360. C ne. Nejvyšší sytost, kterou obrazovka zvládne, závisí na hue i na lightness. Táhni za chroma nahoru, dokud prohlížeč nezačne ořezávat — a pak přepni hue nebo lightness a najdi strop znovu.

Sloupečky jsou strop chroma pro dvanáct hue při zvolené lightness. Osa chroma je pevná, takže se výšky dají srovnávat i mezi jednotlivými lightness — a je vidět, že s krajními hodnotami jasu se celý obrys srazí. Není to kruh se stejným poloměrem.

Dvanáct hue, konstantní lightness

/* HSL bere lightness jako pozici mezi
   černou a bílou — ne jako vjem. */
.hv-sweep--hsl .hv-chip {
  --hv-fill: hsl(var(--hv-h) 70% 50%);
}

/* V oklch je L perceptuální a drží
   napříč celým hue kruhem. */
.hv-sweep--oklch .hv-chip {
  --hv-fill: oklch(65% 0.13 var(--hv-h));
}

Strop chroma

/* Strop závisí na hue I na lightness,
   proto se dopočítává, ne zapisuje. */
.hv-gamut__swatch {
  background: oklch(var(--hv-gl) var(--hv-gc) var(--hv-gh));
}

.hv-gamut__swatch--max {
  background: oklch(var(--hv-gl) var(--hv-gmax) var(--hv-gh));
}
