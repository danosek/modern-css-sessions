linear-gradient(in oklch shorter hue,<barva>,<barva>)
Zvýrazněná část je nepovinná. Vynecháš ji a nedostaneš chybu — dostaneš jiný přechod. Metoda hue (shorter, longer, increasing, decreasing hue) má smysl jen v polárních prostorech — oklch, lch, hsl, hwb. Kudy přesně vede, je demo D2.

Jeden pár, čtyři prostory

Modrá a žlutá, stejná délka, stejné krajní barvy. Liší se jediné slovo v zápisu — prostor, ve kterém prohlížeč mezi barvami interpoluje. Kolík uprostřed pruhu nese color-mix() v témž prostoru, tedy tutéž polovinu; proto s pruhem splývá.

Co je výchozí prostor, když ho nenapíšeš? Jsou-li všechny zastávky klasické barvy (pojmenovaná, #hex, rgb(), hsl()), interpoluje se v sRGB. Stačí ale jediná zastávka moderním zápisem — oklch(), lab(), color() — a výchozím prostorem je oklab. Platí to i pro color(srgb 1 1 0), což je tatáž žlutá jako yellow: barva stejná, výchozí prostor jiný.

CSS Color 4 předepisuje jako výchozí oklab; sRGB u klasických barev drží prohlížeče kvůli zpětné kompatibilitě — přechodů psaných hexem je na webu příliš, než aby se jim dal změnit vzhled.

Dvě poznámky k číslům výše. V in oklch je spočítaná polovina modré a žluté sytější, než sRGB unese, takže se cestou na displej zkrouhne do gamutu; změřená chroma je proto strop displeje, ne výsledek výpočtu. A hsl(240) do hsl(60) je přesně 180 stupňů, takže shorter hue nemá kratší stranu a jde se tak, jak je to zapsané — dolů přes zelenou.

Jeden pár, čtyři prostory

/* Pruh nese přechod, kolík uprostřed
   změřenou barvu v polovině. */
.ip-strip { background: var(--ip-grad); }

.ip-probe,
.ip-end__swatch { background: var(--ip-sample); }

/* sRGB sčítá kanály. Modrá a žlutá jsou
   protilehlé, takže se vyruší do šedé. */
.ip-row--srgb {
  --ip-grad: linear-gradient(in srgb to right, blue, yellow);
  --ip-sample: color-mix(in srgb, blue, yellow);
}

/* Přímka v perceptuálním prostoru: chroma
   klesne, ale ne na nulu. */
.ip-row--oklab {
  --ip-grad: linear-gradient(in oklab to right, blue, yellow);
  --ip-sample: color-mix(in oklab, blue, yellow);
}

/* Polární souřadnice: chroma se vede zvlášť
   od hue, takže sytost drží. */
.ip-row--oklch {
  --ip-grad: linear-gradient(in oklch to right, blue, yellow);
  --ip-sample: color-mix(in oklch, blue, yellow);
}

/* Taky polární, ale po kruhu HSL: sytost
   drží a hue si zajde přes zelenou. */
.ip-row--hsl {
  --ip-grad: linear-gradient(in hsl to right, blue, yellow);
  --ip-sample: color-mix(in hsl, blue, yellow);
}

Vynechaný prostor na brand páru

/* Tokeny palety jsou oklch, tedy moderní
   zápis: výchozí prostor je oklab. */
.ip-row--token {
  --ip-grad: linear-gradient(to right, var(--dixie-60), var(--oxley-60));
  --ip-sample: color-mix(in oklab, var(--dixie-60), var(--oxley-60));
}

/* Tytéž barvy klasickým zápisem: jediná
   změna, a výchozí prostor je sRGB. */
.ip-row--legacy {
  --ip-grad: linear-gradient(to right, rgb(220 143 7), rgb(120 155 129));
  --ip-sample: color-mix(in srgb, rgb(220 143 7), rgb(120 155 129));
}

/* Napsaný prostor: polovina zůstane na
   oblouku mezi hue 71 a 153. */
.ip-row--brand {
  --ip-grad: linear-gradient(in oklch to right, var(--dixie-60), var(--oxley-60));
  --ip-sample: color-mix(in oklch, var(--dixie-60), var(--oxley-60));
}
