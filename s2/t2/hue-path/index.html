Kam se metoda píše

linear-gradient(in oklch longer hue to right, <barva>, <barva>)
barevný prostor — o něm je vedlejší demo t2 D1 metoda hue — o té je tohle demo Metoda stojí za názvem prostoru a je volitelná; když chybí, platí shorter hue. Přijmou ji jen polární prostory, tedy oklch, lch, hsl a hwb — jen ty mají hue jako samostatnou souřadnici. Pravoúhlé prostory (srgb, srgb-linear, oklab, lab, xyz) žádnou hue složku nemají, takže je za jejich názvem chyba v zápisu.

Vedlejší demo t2 D1 řeší, ve kterém prostoru se přechod počítá; tady jde o to, kudy se v tom prostoru jde. Následující dva řádky mají tutéž metodu a liší se jediným písmenem v názvu prostoru. Pod pásem je hodnota, kterou po nich prohlížeč vrátí z background-image.

platné · oklch je polární

Čtyři jména, jeden pár

Pár drží lightness 70 % i chroma 0,12 a hýbe jen hue: 71 je odstín brand primary, 153 brand secondary. Čtverečky v pásu si tutéž barvu nechávají spočítat funkcí color-mix() se stejnou metodou — že v pásu opticky zmizí, je důkaz, že se měří cesta toho gradientu. Pod pásem je hue odečtená z vykreslených pixelů na 10, 30, 50, 70 a 90 % jeho délky a celková ujdená vzdálenost.

Prohoď pořadí zastávek

Tyhle dva pásy jdou z hue 153 do hue 71, tedy obráceně než výše. Délka je vlastnost páru: shorter hue ujde v obou pořadích stejně. Směr je vlastnost pořadí: increasing hue si ho drží, a proto mu z krátkého oblouku vyjde ten dlouhý.

Duha: longer hue z barvy do sebe

Oba pásy mají obě zastávky totožné — hue 71 na obou koncích. Rozdíl v hodnotě barvy je nula, takže shorter hue nemá kam jít a přechod je plocha. longer hue si vezme doplněk do 360° a obejde celý kruh. Tohle je jediný praktický způsob, jak duhu v CSS zapsat dvěma zastávkami.

in oklch longer hue71 → 71

Kratší oblouk mezi hue 71 a 153 měří 82°, delší 278° — a 82 + 278 = 360. Dvě hue jsou na kruhu vždycky spojené právě dvěma cestami, takže shorter hue a longer hue jsou doplňky do 360° a increasing hue a decreasing hue jsou tytéž dvě cesty pojmenované podle směru. Které jméno padne na kterou cestu, rozhoduje pořadí zastávek: pro pár 71 → 153 je increasing ta krátká, pro 153 → 71 ta dlouhá. Duha drží chroma 0,12, protože při 0,152 (jako --dixie-60) část kruhu vypadne z sRGB a gamut mapping ji zploští.

Metoda za názvem prostoru

/* Metoda chybí, takže platí shorter hue. */
.hp-band--default .hp-band__fill {
  background-image: linear-gradient(in oklch to right, var(--hp-from), var(--hp-to));
}

/* Kratší ze dvou oblouků. */
.hp-band--shorter .hp-band__fill {
  background-image: linear-gradient(in oklch shorter hue to right, var(--hp-from), var(--hp-to));
}

/* Delší oblouk, tedy doplněk do 360°. */
.hp-band--longer .hp-band__fill {
  background-image: linear-gradient(in oklch longer hue to right, var(--hp-from), var(--hp-to));
}

/* Hue jen roste, ať je oblouk jakkoli
   dlouhý. */
.hp-band--increasing .hp-band__fill {
  background-image: linear-gradient(in oklch increasing hue to right, var(--hp-from), var(--hp-to));
}

/* Hue jen klesá. */
.hp-band--decreasing .hp-band__fill {
  background-image: linear-gradient(in oklch decreasing hue to right, var(--hp-from), var(--hp-to));
}

Pár a pořadí zastávek

/* Pár drží L i C, hýbe jen hue. */
:root {
  --hp-a: oklch(70% 0.12 71);
  --hp-b: oklch(70% 0.12 153);
}

.hp-band {
  --hp-from: var(--hp-a);
  --hp-to: var(--hp-b);
}

/* Prohozené pořadí zastávek. */
.hp-band--swap {
  --hp-from: var(--hp-b);
  --hp-to: var(--hp-a);
}

/* Oba konce tatáž barva — vstup do duhy. */
.hp-band--self {
  --hp-to: var(--hp-a);
}

Vzorek: tatáž metoda v color-mix()

/* --hp-at je současně pozice v pásu i váha,
   takže když vzorek v pásu zmizí, měříme
   opravdu cestu toho gradientu. */
.hp-probe {
  inset-inline-start: var(--hp-at);
  background: color-mix(in oklch var(--hp-mix),
      var(--hp-from) calc(100% - var(--hp-at)), var(--hp-to));
}

.hp-probe--30 { --hp-at: 30%; }
