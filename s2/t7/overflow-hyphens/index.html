overflow-wrap·hyphens

Dva nástroje na jeden problém

overflow-wrap: break-word Poslední instance. Zlomí slovo kdekoli, i mezi slabikami nebo uvnitř identifikátoru. Nepotřebuje vědět nic o jazyku, a proto je bezpečné pro URL, hashe a čísla dokladů. hyphens: auto Dělení podle slovníku jazyka, se spojovníkem. Vypadá dobře, ale potřebuje lang na elementu nebo předkovi — jinak prohlížeč nevybere slovník a neudělá nic. word-break: break-all Zlomí vždycky na konci řádku, ne až když je nutno. Pro běžný text je to špatná volba; uvádíme ho, aby se nepletl s předchozími dvěma.

Týž text ve čtyřech nastaveních

Zužuj box sliderem. Pod každým vzorkem je změřeno, jestli obsah přetéká a na kolik řádků padl. Rozdíl mezi druhým a třetím vzorkem je vidět jen očima: oba se vejdou na stejný počet řádků, ale hyphens zlomí se spojovníkem a na hranici slabiky, zatímco overflow-wrap uprostřed slova a bez něj.

Past: hyphens bez lang

Oba vzorky mají hyphens: auto. Vlevo dědí lang="cs" z dokumentu, vpravo ho má přepsaný na prázdno — a tím se slovník vypne. Skoro vždycky je to důvod, proč dělení „nefunguje".

overflow-wrap: break-word dej globálně tam, kde se objevují uživatelská data — jména souborů, URL, čísla dokladů. Je to pojistka proti rozstřelenému layoutu a nic nestojí.

hyphens: auto nasazuj na běžnou prózu v úzkých sloupcích a vždycky zkontroluj, že dokument má správný lang. V českém textu dělá největší rozdíl, protože čeština má dlouhá slova a skloňováním jich ještě přidá.

Čtyři nastavení

/* Výchozí: slovo z boxu vyleze. */
.oh-box--none { overflow-wrap: normal; }

/* Zlom kdekoli, až když nemá jinou možnost. */
.oh-box--anywhere { overflow-wrap: break-word; }

/* Dělení podle slovníku — potřebuje lang. */
.oh-box--hyphens { hyphens: auto; }

/* Obojí: dělení, kde to jazyk dovolí,
   násilný zlom jako pojistka. */
.oh-box--both {
  hyphens: auto;
  overflow-wrap: break-word;
}
