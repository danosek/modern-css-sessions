text-wrap: balance · pretty · stable

Tři hodnoty, tři různé problémy se zalomením.

text-wrap

Čtyři hodnoty, čtyři strategie

wrap Výchozí. Greedy: plní řádek, dokud se další slovo vejde. Nejrychlejší, ale poslední řádek může zůstat s jedním slovem. balance Vyrovná délky řádků. Pro nadpisy a krátké bloky, protože se to počítá jen do několika řádků. pretty Řeší sirotka na konci dlouhého textu. Délky nevyrovnává. stable Drží zlomy nad kurzorem při psaní, takže se už napsaný text nepřeskládá pod rukama.

balance — nadpis, který nenechá sirotka

Oba sloupce mají v každém okamžiku shodnou šířku, takže se lámou za stejných podmínek — liší se jedině tou deklarací. Pod nadpisem je délka každého řádku ve znacích a rozdíl mezi nejdelším a nejkratším.

Roční uzávěrka skladových pohybů

Vyvažování je drahé, takže ho prohlížeč dělá jen do několika řádků — strop je šest. Nad ním se deklarace tiše ignoruje a text se láme greedy. Pro nadpisy to nevadí, ty bývají do tří řádků.

pretty — sirotek na konci odstavce

Táhni za slider, dokud se vlevo neobjeví jednoslovný poslední řádek. Vpravo stejný text s pretty. Pod odstavcem je délka posledního řádku a počet slov na něm — sirotek je jednoslovný konec, ne krátký řádek.

stable — zalomení, které neposkakuje

Obě pole jsou editovatelná. Klikni do nich a piš doprostřed textu — vlevo se zlomy přeskládají i nad kurzorem, vpravo zůstanou. Pro komentáře, chatová okna a formulářové náhledy je to rozdíl mezi klidným a nervózním rozhraním.

Kdy co: balance na nadpisy, prakticky vždycky. pretty globálně na běžný text — rozdíl je úzký a vzniká jen při některých šířkách, takže se neladí po blocích. stable všude, kde uživatel text píše.

Čtyři hodnoty

/* Výchozí greedy. */
.tw-greedy { text-wrap: wrap; }

/* Vyrovná délky řádků — na nadpisy. */
.tw-balance { text-wrap: balance; }

/* Řeší sirotka — na dlouhý text. */
.tw-pretty { text-wrap: pretty; }

/* Drží zlomy při psaní. */
.tw-stable { text-wrap: stable; }
