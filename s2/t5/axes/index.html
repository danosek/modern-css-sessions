font-variation-settings

Jeden soubor, spojité osy. Quattro má jedinou — a není to wght.

font-variation-settings
font-variation-settings: "wght" 700, "wdth" 87;
tag osy: čtyři znaky v uvozovkách hodnota bez jednotky, spojitá Variabilní font je jeden soubor, ve kterém jsou řezy uložené jako osy — spojité rozsahy, ne hotové varianty. Kolik os font má a jaké, je věc toho konkrétního souboru; nic se nedá předpokládat.

Obecně: registrované a vlastní osy

Pět os je registrovaných ve specifikaci. Mají tag malými písmeny a vlastní CSS vlastnost — tou je nastavuj, ne přes font-variation-settings. Vlastnost se dá animovat, dědí se po částech a prohlížeč z ní pozná, kdy má sáhnout po syntetickém řezu.

osa co mění vlastnost v CSS
wghttloušťkufont-weight

opszoptickou velikostfont-optical-sizing

Cokoli dalšího je vlastní osa. Má tag velkými písmeny, žádnou vlastnost v CSS nemá, a proto se dá nastavit jedině přes font-variation-settings. Zbytek dema je o jedné takové.

Konkrétně: iA Writer Quattro

Odteď je řeč o jednom souboru — o písmu, kterým je vysázený tenhle text. iA Writer Quattro nemá ani jednu z těch pěti registrovaných os, má jedinou vlastní: SPCG. Rozsah v tabulce je zapsaný ve fontu, poslední sloupec je změřený v prohlížeči — demo projede hodnoty po jedné a hlásí, kde se text přestane měnit.

Živé slidery

Oba slidery jdou schválně za konce os. Za hranicí se hodnota utne a text se přestane hýbat.

400

Tímhle nehneš ničím — a to je první lekce. Quattro osu wght nemá, takže 400 a 700 vykreslí úplně stejně. Spectro přitom v @font-face slibuje font-weight: 400 700, takže tučné nakonec dopočítá prohlížeč sám.

0

Tenhle ano. SPCG mění rozestup znaků a je to jediná osa, kterou tenhle font má. Rozsah je 0 až 150 — nad 150 se už nestane nic, font dál neumí.

Co osa SPCG doopravdy dělá

Čtyři řádky se liší jedinou hodnotou osy. Vpravo je změřená šířka deseti úzkých a deseti širokých znaků — vidíš na nich, že osa přidá každému znaku stejně, ne poměrně.

Osa přidá každému znaku tentýž kus rozestupu, ne poměrný: „i" i „M" povyrostou o stejné číslo, takže poměr M/i klesá, ale k jedné nedojde. Monospace z Quattra tedy nebude — poslední řádek je jiný soubor, ne jiná hodnota osy. Popisu „Quattro → Duo → Mono" nevěř, změř si ho.

Registrovanou osu nastavuj její vlastností (font-weight, font-stretch, font-optical-sizing), ne font-variation-settings — vlastnost se dá animovat, dědí se po částech a prohlížeč z ní pozná, kdy má sáhnout po syntetickém řezu. font-variation-settings si nech na osy, které vlastnost nemají. V tomhle repozitáři je to jediná cesta k SPCG.

Dvě osy, jedna deklarace

/* Slidery přepisují jen tahle dvě čísla. */
:root {
  --ax-wght: 400;
  --ax-spcg: 0;
}

/* Tag osy v uvozovkách, pak hodnota. Obě
   osy v jedné deklaraci, oddělené čárkou. */
.ax-sample,
.ax-probe {
  font-variation-settings: "wght" var(--ax-wght), "SPCG" var(--ax-spcg);
}

/* Žebřík rozestupu: řádky se liší jedině
   hodnotou SPCG. */
.ax-rung__spec {
  --ax-rung: 0;
  font-variation-settings: "SPCG" var(--ax-rung);
}

.ax-rung--50 { --ax-rung: 50; }
.ax-rung--150 { --ax-rung: 150; }
