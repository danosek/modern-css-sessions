font-weight vs. "wght"

Spectro počítá bold jako seed + 300. Font tu osu nemá.

font-weight·font-variation-settings
font-weight: 700 vysokoúrovňová vlastnost

Vstupuje do výběru řezu. Prohlížeč hledá ve fontu nejbližší dostupnou váhu, a když žádnou tučnou nenajde, dopočítá ji sám — syntetickým tučným. Dědí se jako číslo, umí bolder / lighter a jde ho animovat.

font-variation-settings: "wght" 700 nízkoúrovňový přístup k ose

Nastavuje osu na řezu, který už je vybraný — výběr řezu tedy neovlivní. Když font osu nemá, neudělá nic a nic nedopočítá. Dědí se jako celý řetězec os, ne po jednotlivých osách.

Kam každá z nich dosáhne

Táž hodnota 700 na dvou fontech tohohle repozitáře. Řádek pod názvem fontu vypisuje tabulky, které JS našel přímo v souboru .woff2 — fvar je tabulka variací, bez ní font žádnou osu nemá.

Dědičnost — řetězec vs. číslo

Rodič nastavuje dvě věci naráz: tučnou kresbu a rozšířené rozestupy osou SPCG (0–150, vlastní osa iA Writer). Potomek chce zpátky jen obyčejnou váhu. Vlevo si o ni řekne osou, vpravo font-weightem. Šířka vzorku je změřená z vykresleného boxu, takže ztrátu rozestupů je vidět v pixelech.

obojí jednou deklarací
rodič { font-variation-settings: "wght" 700, "SPCG" 100 }
Rozestup znaků potomek bez vlastní deklarace
Rozestup znaků potomek { font-variation-settings: "wght" 400 }
váha zvlášť, osa zvlášť
rodič { font-weight: 700; font-variation-settings: "SPCG" 100 }
Rozestup znaků potomek bez vlastní deklarace
Rozestup znaků potomek { font-weight: 400 }

Pět rolí váhy, kolik jich font uveze

Váhy si Spectro dopočítává jako posuny od seedu: thin −200, light −100, medium +100, bold +300. Každý sloupec bere přesně ten token, který z receptu vypadl. Pod vzorkem je pokrytí inkoustem: JS vykreslí tentýž text tímtéž řezem a velikostí na canvas, sečte tmavost pixelů a porovná s nejsvětlejším krokem řádku. Shodné číslo znamená shodné vykreslení.

Recept na váhy se fontu neptá, co umí. U main fontu se seedem 400 z něj vyjde 200–700, zatímco osa wght jde 400–700: thin a light spadnou na 400. Je to pořád řez z fontu, jen dvě role vedou na tutéž kresbu. U headings je seed 700, takže bold vyjde 1000 — Departure Mono má ale jediný řez a osu wght vůbec ne, a tak čtyři z pěti rolí končí na jednom a tomtéž syntetickém tučném. Není to chyba v jednom tokenu, je to důsledek obecného receptu na konkrétním fontu.

Pro nadpisy z toho plyne volba: font s osou wght, nebo přiznat, že hierarchii nese velikost a jedna váha. Wrapper těchhle dem dělá to druhé — .demo-title má font-weight: normal, aby si nadpis nevzal syntetické tučné.

Dosah obou vlastností

/* Vysokoúrovňová vlastnost: jde do výběru
   řezu, a když tučný chybí, prohlížeč ho
   dopočítá syntetickým tučným. */
.wa-cell--weight .wa-cell__sample { font-weight: 700; }

/* Nízkoúrovňový přístup k ose: nastaví ji
   na už vybraném řezu. Když osa není,
   neudělá nic — a nic nedopočítá. */
.wa-cell--axis .wa-cell__sample { font-variation-settings: "wght" 700; }

Dědičnost — řetězec vs. číslo

/* Rodič nastaví dvě osy jednou deklarací. */
.wa-inherit--axis .wa-inherit__parent { font-variation-settings: "wght" 700, "SPCG" 100; }

/* Potomek přepíše jednu z nich a SPCG se
   vytratí: dědí se celý řetězec, ne
   jednotlivé osy. */
.wa-inherit--axis .wa-inherit__sample--override { font-variation-settings: "wght" 400; }

/* Vpravo nese váhu font-weight a osa má
   vlastní deklaraci. */
.wa-inherit--weight .wa-inherit__parent {
  font-weight: 700;
  font-variation-settings: "SPCG" 100;
}

/* Potomek přepíše číslo, které se dědí
   samo za sebe, takže osa z rodiče platí
   dál. */
.wa-inherit--weight .wa-inherit__sample--override { font-weight: 400; }
