Surové OpenType tagy a dva důvody, proč jimi nezačínat.

font-feature-settings

Dvě cesty k téže featuře

Většina OpenType featur má v CSS vlastnost — font-variant-caps, font-variant-numeric, font-variant-ligatures. A pak je tu font-feature-settings, kam se píšou surové čtyřznakové tagy. Vypadá to jako totéž, ale chová se to jinak ve dvou věcech.

font-variant-* Prohlížeč featuru dopočítá, když ji font nemá — kapitálky zmenší z verzálek, zlomky složí z číslic. Vlastnosti se navíc skládají: každá řeší svou skupinu nezávisle. font-feature-settings Pošle tag přímo do fontu. Nesyntetizuje nic, a celý výčet se přepisuje — potomek nepřidává, ale nahrazuje.

Za prvé: nesyntetizuje

Vzorky jsou vysázené písmem tohohle repozitáře, tedy iA Writer Quattro. To kapitálky nemá. Pod každým je změřená šířka proti kontrolnímu vzorku.

bez deklarace
Kapitálky Text kontrolní vzorek
font-variant-caps: small-caps
Kapitálky Text
font-feature-settings: "smcp" 1
Kapitálky Text

Prostřední vzorek prohlížeč dopočítal — zmenšil verzálky. Pravý se nezměnil vůbec, protože tag smcp v tom souboru není. Ani jedno není chyba — jsou to dvě různá chování.

Za druhé: přepisuje celý výčet

font-feature-settings se dědí jako jeden řetězec, ne jako sada nezávislých přepínačů. Když potomek zapne jednu featuru, ostatní tím vypne. Vzorky jsou systémovým fontem, který tnum i smcp doopravdy má.

font-feature-settings
1111 8888 1111 8888
font-variant-*
1111 8888 1111 8888

V každé buňce jsou dvě čísla vedle sebe: první dědí od rodiče, druhé má vlastní deklaraci. Vlevo se šířky rozejdou, protože potomek tabulární sadu shodil. Vpravo drží, protože vlastnosti se skládají.

Sahej po font-variant-*. Je to graceful cesta — když font featuru nemá, prohlížeč ji dopočítá nebo tiše přeskočí, a vlastnosti se v kaskádě skládají.

font-feature-settings si nech na vlastní featury, které vlastnost nemají — stylistické sady ss01 a výš, alternativy salt, znakové varianty. A když ho použiješ, vypisuj vždycky celý výčet, ne jen tu jednu featuru, kterou právě měníš.

Syntéza vs. surový tag

/* Vlastnost kapitálky dopočítá, i když
   je font nemá. */
.fs-caps--variant {
  font-variant-caps: small-caps;
}

/* Surový tag ne. Buď je ve fontu, nebo
   se nestane nic. */
.fs-caps--raw {
  font-feature-settings: "smcp" 1;
}

Přepsání celého výčtu

/* Rodič zapne dvě featury zároveň. */
.fs-reset__parent {
  font-feature-settings: "tnum" 1, "smcp" 1;
}

/* Potomek zapne jednu — a druhou zahodí. */
.fs-reset__child {
  font-feature-settings: "smcp" 1;
}

/* Vlastnosti se naopak skládají. */
.fs-ok__parent {
  font-variant-numeric: tabular-nums;
  font-variant-caps: small-caps;
}

.fs-ok__child {
  font-variant-caps: small-caps;
}
