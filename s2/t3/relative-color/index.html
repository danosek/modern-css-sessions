S2 – Colors & Typography

oklch(from …)

Odvoď tint, shade i komplement bez znalosti hodnoty.

oklch(from …)
oklch(from <zdroj> l c h / alpha)
from <zdroj>
Rozloží zdrojovou barvu na složky. Zdroj je libovolná barva — klidně var(…) nebo currentColor.
l c h alpha
Uvnitř funkce to nejsou klíčová slova, ale čísla: l v rozsahu 0–1 (ne procenta), c zhruba 0–0,4, h ve stupních, alpha 0–1.
calc(h + 180)
Na místě každé složky smí stát výpočet. Co nepřepíšeš, projde ze zdroje beze změny.

Pět odvozenin dole nezná ani jednu hodnotu barvy — všechny sahají po témž var(--rc-src). Přepínač přepisuje jen tenhle jediný token; odvozovací pravidla zůstávají doslova stejná.

zdroj
var(--rc-src)

Token, který přijde odjinud. Jeho hodnotu nikde v tomhle souboru nepíšeme.

světlejší
oklch(from var(--rc-src) calc(l + 0.15) c h)

Tint — podbarvení řádku, hover na tmavém podkladu.

tmavší
oklch(from var(--rc-src) calc(l - 0.15) c h)

Shade — okraj, stisknutý stav, text na světlé ploše.

odbarvená
oklch(from var(--rc-src) l calc(c * 0.3) h)

Neaktivní stav. Světlost drží, ubývá jen sytost.

komplement
oklch(from var(--rc-src) l c calc(h + 180))

Protilehlá barva — druhá série v grafu, zvýraznění rozdílu.

poloprůhledná
oklch(from var(--rc-src) l c h / 50%)

Překryv, výběr v tabulce, stín focus ringu.

color-mix() z předchozího dema míchá dvě hotové barvy; oklch(from …) naopak jednu rozebere na složky a nechá tě s nimi počítat. Spectro odvozuje ve světlém tématu hover jako lightness × 0,95 při nezměněném chroma i hue — tedy přesně oklch(from var(--surface-base) calc(l * 0.95) c h).

Zdroj — jediné místo, kde je token napsaný

/* Jediné místo v souboru, kde padne
   konkrétní token. Odvozeniny níž
   o jeho hodnotě nevědí nic. */
.rc-derive[data-src="brand-primary"] { --rc-src: var(--text-brand-primary); }

.rc-derive[data-src="brand-secondary"] { --rc-src: var(--text-brand-secondary); }

.rc-derive[data-src="status-error"] { --rc-src: var(--text-status-error); }

.rc-derive[data-src="status-information"] { --rc-src: var(--text-status-information); }

Odvozeniny — při přepnutí zdroje se nemění

/* Zdroj beze změny, pro srovnání. */
.rc-derive__swatch--source { background: var(--rc-src); }

/* Přepsané je jen l; c a h projdou dál
   tak, jak je funkce našla ve zdroji. */
.rc-derive__swatch--lighter { background: oklch(from var(--rc-src) calc(l + 0.15) c h); }

.rc-derive__swatch--darker { background: oklch(from var(--rc-src) calc(l - 0.15) c h); }

/* Chroma na třetinu: táž barva, míň syté. */
.rc-derive__swatch--muted { background: oklch(from var(--rc-src) l calc(c * 0.3) h); }

/* h je úhel ve stupních, +180 dá
   protilehlou barvu. Přes 360 se
   normalizuje. */
.rc-derive__swatch--complement { background: oklch(from var(--rc-src) l c calc(h + 180)); }

/* Alfa se odděluje lomítkem jako jinde.
   Nemusí se počítat, stačí přepsat. */
.rc-derive__swatch--alpha { background: oklch(from var(--rc-src) l c h / 50%); }
