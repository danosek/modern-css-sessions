contrast-color()

Čitelný text na libovolném povrchu, spočítaný za běhu.

contrast-color()
contrast-color(<barva pozadí>) → black nebo white
Argumentem je barva, proti které se má text číst. Dnes vrací jen černou, nebo bílou. CSS Color 6 počítá s tím, že půjde poslat i vlastní seznam kandidátů — contrast-color(#dc8f09, tan, sienna) — a funkce z nich vybere. Zatím to neumí žádný prohlížeč.

Živý důkaz — osm povrchů, jedno pravidlo

Horní řádek si barvu nechá spočítat funkcí, dolní bere správný Spectro token pro ten povrch. Oba jsou čitelné — rozdíl je v ceně: nahoře jedno pravidlo pro všech osm buněk, dole 558 předpočítaných tokenů pro 186 povrchů. Přepni téma a sleduj štítek dole v buňce.

Barva, kterou generátor neviděl

Vyber barvu, nebo si nech poslat náhodnou, jako by přišla z API. Token pro ni neexistuje a nikdy existovat nebude — text je přesto čitelný.

Kde je hranice

Týž povrch --surface-dixie-strong, vlevo funkce, vpravo tokeny. Rozdíl není v čitelnosti, ale v odstupňování.

Třikrát tatáž hodnota. Hierarchii musí nést velikost nebo řez.

A hlavně: token se dá opsat. Funkci musíš volat s povrchem, na kterém text leží, takže tu barvu máš v CSS dvakrát. Jakmile bys chtěl průhlednost nebo jiný odstín, skládáš výsledek z několika hodnot. Proto tuhle funkci ve Spectru nepoužíváme.

Tři odstíny: méně důležitá role je blíž povrchu pod ní. Hue 71 drží všechny tři.

Chystá se rozšířená syntaxe, kterou půjde vybrat algoritmus výpočtu — WCAG 2.1, nebo APCA. Seed Spectra týž přepínač už má: contrastAlgorithm. Rozdíl je v tom, kdy se vyhodnotí — u Spectra v Motivu, u funkce až v prohlížeči.

Demo — jedno pravidlo, osm povrchů

/* Buňka zná jen svůj povrch. Barvu textu
   z něj funkce dopočítá sama. */
.cc-proof__cell {
  background: var(--cc-surface);
  color: contrast-color(var(--cc-surface));
}

/* Osm reálných povrchů Spectra: jediné,
   čím se buňky mezi sebou liší. */
.cc-proof__cell--dixie-strong { --cc-surface: var(--surface-dixie-strong); }
.cc-proof__cell--navy-contrast { --cc-surface: var(--surface-navy-contrast); }
/* … a dalších šest ve style.css */

/* Kontrolní vzorek: správný token pro ten
   povrch. Čitelný taky — jen jich musí
   existovat 558. */
.cc-proof__cell--dixie-strong .cc-proof__line--fixed {
  color: var(--text-primary-on-surface-dixie-strong);
}

Hranice — odstíny umí jen tokeny

/* Hranice funkce: tři role textu na jednom
   povrchu dostanou tutéž barvu. */
.cc-limit__col--fn {
  background: var(--surface-dixie-strong);
  color: contrast-color(var(--surface-dixie-strong));
}

/* Spectro tytéž tři role odstíní a drží
   hue povrchu. To funkce neumí. */
.cc-limit__col--tokens {
  background: var(--surface-dixie-strong);
  color: var(--text-primary-on-surface-dixie-strong);
}

.cc-limit__row--secondary { color: var(--text-secondary-on-surface-dixie-strong); }
.cc-limit__row--disabled { color: var(--text-disabled-on-surface-dixie-strong); }
