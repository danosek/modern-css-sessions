Přepni směr čtení — logické vlastnosti se překlopí, fyzické zůstanou vlevo

inline-size·block-size

Obě karty mají identický obsah i layout — pruh, ikonu a velké odsazení na začátku. Liší se jen tím, čím jsou nastylované: fyzickými, nebo logickými vlastnostmi. Přepni do RTL a sleduj: u fyzické karty zůstanou pruh i ikona vlevo (text ale teče zprava → rozpadne se to), u logické se překlopí na začátek čtení a layout zůstane v pořádku.

Responzivní karta

Stejný obsah, stejný layout — pruh, ikona i odsazení na začátku. Liší se jen to, čím jsou nastylované. Přepni směr čtení a porovnej.

UI Layout RTL 
.card {
  border-left: 8px solid;
  padding-left: 3.5rem;
}

.card .ico {
  left: 0.75rem;
}
Logické vlastnosti
★

Responzivní karta

Stejný obsah, stejný layout — pruh, ikona i odsazení na začátku. Liší se jen to, čím jsou nastylované. Přepni směr čtení a porovnej.

UI Layout RTL 
.card {
  border-inline-start: 8px solid;
  padding-inline-start: 3.5rem;
}

.card .ico {
  inset-inline-start: 0.75rem;
}

Logical Properties

/* Fyzické vlastnosti jsou vázané na viewport (top/right/bottom/left) */
/* Logické vlastnosti jsou vázané na směr psaní (block / inline osy) */

/* Inline osa → v LTR = vodorovná (←→), v RTL se otočí */
/* Block osa  ↓ v LTR = svislá (↑↓), nemění se */
