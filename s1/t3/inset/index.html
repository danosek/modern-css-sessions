Zkratka inset

inset

Vlastnost inset nahrazuje všechny čtyři poziční vlastnosti najednou a funguje stejně jako margin či padding co do pořadí hodnot. Box uvnitř containeru je odsazený o 20 % z každé strany — táhni posuvníkem a sleduj, jak se obě verze (fyzická i logická) mění úplně stejně.

inset: 20%
Fyzicky · 4 vlastnosti
box
Logicky · inset
box 
.box {
  position: absolute;
  top: 20%;
  right: 20%;
  bottom: 20%;
  left: 20%;
}
.box {
  position: absolute;
  inset: 20%;
}

Pozicování — inset

/* Fyzicky — 4 vlastnosti: */
.box {
  position: absolute;
  top: 20%; right: 20%; bottom: 20%; left: 20%;
}

/* Logicky — zkratka inset: */
.box {
  position: absolute;
  inset: 20%;         /* = top right bottom left = 20% */
}

/* inset funguje jako margin/padding shorthand: */
.panel {
  inset: 1rem 2rem;         /* block: 1rem, inline: 2rem */
  inset-inline-start: 0;    /* = left v LTR, right v RTL */
}
