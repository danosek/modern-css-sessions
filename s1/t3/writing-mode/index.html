Logické vlastnosti a writing-mode

writing-mode

Obě karty mají identický obsah i barevný pruh na začátku. Liší se jen tím, čím je pruh nastylovaný — fyzicky (border-left), nebo logicky (border-inline-start). Přepni na vertical-rl a sleduj pruh: u fyzické karty zůstane vlevo (ale text teče shora dolů → je mimo začátek), u logické se překlopí nahoru, na začátek řádku textu.

Fyzické vlastnosti

Štítek

Stejný obsah, stejný pruh na začátku. Přepni writing-mode a sleduj, kam se pruh přesune. 

.card {
  border-left: 8px solid;
  padding-left: 2.5rem;
}
Logické vlastnosti

Štítek

Stejný obsah, stejný pruh na začátku. Přepni writing-mode a sleduj, kam se pruh přesune. 

.card {
  border-inline-start: 8px solid;
  padding-inline-start: 2.5rem;
}
border-inline-start vždy označuje začátek řádku textu — proto se ve vertical-rl překlopí nahoru. border-left je vázaný na viewport, takže zůstane vlevo bez ohledu na směr textu.

writing-mode a logické vlastnosti

/* vertical-rl → text teče shora dolů, řádky zprava doleva.
   Začátek řádku (inline-start) je teď NAHOŘE.                 */

/* Fyzicky — border-left je vázaný na viewport, zůstane vlevo,
   takže je mimo začátek svislého textu */
.card-physical {
  writing-mode: vertical-rl;
  border-left: 8px solid;     /* pořád vlevo */
  padding-left: 2.5rem;       /* pořád vlevo */
}

/* Logicky — border-inline-start se otočí na začátek řádku (nahoru) */
.card-logical {
  writing-mode: vertical-rl;
  border-inline-start: 8px solid;  /* = nahoře */
  padding-inline-start: 2.5rem;    /* = nahoře */
}
