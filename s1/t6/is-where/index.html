:is() · :where()

Stejné seskupení, jediný rozdíl je specificita

:is()·:where()

Obě skupiny cílí na stejný prvek a po nich přijde stejné jednoduché pravidlo .row. :is() přebírá specificitu nejsilnějšího argumentu (zde #id), kdežto :where() má specificitu vždy 0.

:is() — drží specificitu

:is(#hot, .row) {  /* (1,0,0) */
  background: var(--surface-brand-secondary-strong);
}
.row {             /* (0,1,0) — později */
  background: var(--surface-brand-primary-strong);
}

>> vyhrálo :is() pravidlo

:is(#hot, .row) = (1,0,0). Pozdější .row (0,1,0) ji nepřebije.

:where() — specificita 0

:where(#hot2, .row2) {  /* (0,0,0) */
  background: var(--surface-brand-secondary-strong);
}
.row2 {                 /* (0,1,0) — později */
  background: var(--surface-brand-primary-strong);
}

>> vyhrálo pozdější .row2

:where(#hot2, .row2) = 0. Pozdější .row2 (0,1,0) ji přebije — cokoli > 0.
