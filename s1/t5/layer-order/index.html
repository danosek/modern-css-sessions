>> S @layer

.btn.btn-primary

.btn-util

Vyhrává nižší specificita — je ve vyšší vrstvě.

>> Bez @layer

.btn.btn-primary-nl
(0,2,0) · [ WIN ]
.btn-util-nl
(0,1,0) · pozdější v kódu

Vyhrává vyšší specificita — klasická kaskáda.

Stejné selektory, jeden rozdíl: @layer

/* S @layer — pořadí vrstvy bije specificitu */
@layer components, utilities;

@layer components { .btn.btn-primary { background: tomato; } }  /* (0,2,0) → prohrává */
@layer utilities  { .btn-util       { background: teal;   } }  /* (0,1,0) → VYHRÁVÁ */

/* Bez @layer — vyhraje vyšší specificita (klasická kaskáda) */
.btn.btn-primary-nl { background: tomato; }   /* (0,2,0) → VYHRÁVÁ */
.btn-util-nl        { background: teal;   }   /* (0,1,0) → prohrává */
