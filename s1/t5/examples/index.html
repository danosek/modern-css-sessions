@layer·revert-layer
@import "lib" layer(reset) Knihovna uzamčená v reset — naše komponenta ji přebije bez !important
#lib .lib-btn
@layer reset (knihovna) · (1,1,0)
.lib-btn
@layer components (naše) · (0,1,0) · [ WIN ]
revert-layer Vrátí hodnotu na to, co definovala nižší vrstva

base nastaví podklad, components ho přebije. background: revert-layer v components ho vrátí zpět na hodnotu z base — ne na průhlednou.

@layer { … } bez jména je vždy nižší než kterákoli pojmenovaná vrstva — bez ohledu na pořadí v kódu.

Pořadí, revert-layer a anonymní vrstva

/* Pořadí deklarováno dopředu — vrstvy lze poté naplnit kdekoli */
@layer reset, base, components, utilities;

/* Knihovna v reset prohraje s naší components — i s vyšší specificitou */
@layer reset      { #lib .lib-btn { background: gray; } }   /* (1,1,0) */
@layer components { .lib-btn      { background: teal; } }   /* (0,1,0) → VYHRÁVÁ */

/* revert-layer vrátí hodnotu na nižší vrstvu (base), ne na initial */
@layer base       { .rv-btn       { background: #333; } }
@layer components { .rv-btn--ghost { background: revert-layer; } }  /* → #333 z base */

/* Anonymní vrstva — VŽDY nižší než pojmenované, i když je v kódu nakonec */
@layer { .btn { background: red; } }   /* nikdy nevyhraje nad pojmenovanou */
