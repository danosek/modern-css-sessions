Vendor CSS · revert-layer

Přepni hodnotu u ghost tlačítka a sleduj, kam se vrátí — o vrstvu níž, nebo až na výchozí styl

@layer·revert-layer
@import "lib" layer(reset) Knihovna uzamčená v reset — naše komponenta ji přebije bez !important
@layer reset (knihovna) (1,1,0)
#lib .lib-btn { background: main-variant }
prohrává — nižší vrstva
@layer components (naše) (0,1,0)
.lib-btn { background: brand-primary }
[ WIN ] — vyšší vrstva
revert-layer Vrátí hodnotu na to, co definovala nižší vrstva
↑ krok 2
↑ krok 3
1 · @layer base (0,1,0)
.rv-btn { background: gray-strong }
podklad — sem se hodnota vrací
2 · @layer components (0,1,0)
.rv-btn { background: brand-primary }
přebíjí krok 1 → normální tlačítko
3 · @layer components (0,1,0)
.rv-btn--ghost { background: revert-layer }

@layer { … } bez jména se řadí podle místa prvního výskytu — úplně stejně jako pojmenovaná vrstva. Její specifikum je jinde: nejde na ni odkázat a každý anonymní blok tvoří novou vrstvu — nedá se později doplnit.

Pořadí, revert-layer a anonymní vrstva

/* Pořadí deklarováno dopředu — vrstvy lze poté naplnit kdekoli */
@layer reset, base, components, utilities;

/* Knihovna v reset prohraje s naší components — i s vyšší specificitou */
@layer reset      { #lib .lib-btn { background: gray; } }   /* (1,1,0) */
@layer components { .lib-btn      { background: teal; } }   /* (0,1,0) → VYHRÁVÁ */

/* revert-layer vrací hodnotu o vrstvu níž (base), ne na výchozí */
@layer base       { .rv-btn        { background: gray; } }   /* 1 — podklad */
@layer components { .rv-btn        { background: teal; }      /* 2 — přebíjí */
                    .rv-btn--ghost { background: revert-layer; } }  /* 3 → gray z base */

/* Tři hodnoty, tři různé cíle — přepínač v demu mění právě tuhle deklaraci:
   (nic)        → zůstane teal z components (krok 2)
   revert-layer → gray z base — jen o JEDNU vrstvu níž
   revert       → až na styl prohlížeče, vrstvy se přeskočí celé  */

/* Anonymní vrstva — řadí se podle prvního výskytu jako každá jiná.
   Nejde na ni odkázat a každý @layer { } blok = nová, uzavřená vrstva */
@layer { .btn { background: red; } }   /* zde poslední → nejvyšší priorita */
