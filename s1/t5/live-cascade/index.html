S1 – Foundations Refresh

Prohoď pořadí vrstev

Přepni pořadí @layer a sleduj, jak nižší specificita ve vyšší vrstvě vyhraje

@layer
↑ výsledek kaskády
@layer components (1,1,0)
#live .lab-btn { background: brand-primary }
@layer utilities (0,1,0)
.lab-btn { background: brand-secondary }

Vítězí pravidlo z pozdější vrstvy — i když má nižší specificitu. Pořadí @layer bije specificitu selektoru.

Pořadí vrstev rozhoduje

/* Pořadí deklarace určuje prioritu — pozdější vrstva vyhrává */
@layer components, utilities;

@layer components {
  #live .lab-btn { background: tomato; }   /* (1,1,0) — VYŠŠÍ specificita */
}
@layer utilities {
  .lab-btn { background: teal; }           /* (0,1,0) — NIŽŠÍ, ale pozdější vrstva → vyhrává */
}
