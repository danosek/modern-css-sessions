max() — minimální šířka

Vrátí největší z hodnot

width·min-width
width: max(50%, 320px) →
50 % nebo minimálně 320 px — vždy větší hodnota
max(50%, 320px)
min-width: 320px ekvivalentní zápis — ale max() přijme i více argumentů
min-width: 320px
Proč max()?

Na rozdíl od min-width přijme max() libovolný počet argumentů a může kombinovat různé jednotky — například max(50vw, 320px, 20rem).

max()

/* max(a, b, …) — vrátí největší hodnotu ze seznamu.
   Výborné pro spodní hranici šířky: buď 50 % nebo min. 320 px — co je větší. */

.container {
  width: max(50%, 320px);
  /* Ekvivalentní: width: 50%; min-width: 320px — ale max() přijme více argumentů */
}

/* Kombinace více jednotek — není možné s min-width */
.sidebar {
  width: max(50vw, 320px, 20rem);
}
