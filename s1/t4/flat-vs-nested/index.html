Nesting vs. Less

Co se z Lessu přepíše jeden na jeden a kde nativní & funguje jinak

&
Less
.card {
  background: …;

  .card__title { font-size: …; }
  &:hover { box-shadow: …; }

  &--featured { border-color: …; }
  &__body { padding: …; }
}
Preprocesor selektory skládá z textu, takže &--featured slepí na .card--featured
Nativní CSS
.card {
  background: …;

  .card__title { font-size: …; }   /* stejné */
  &:hover { box-shadow: …; }        /* stejné */

  /* &--featured — NEFUNGUJE */
  &.card--featured { border-color: …; }
  .card__body { padding: …; }
}
& je skutečný selektor, ne text — slepit ho s příponou nelze
Co je stejné

Vnořený potomek i & před pseudo-třídou, pseudo-elementem a další třídou se chovají jako v Lessu. & smí být i uprostřed: .dark & { … }.

Past 1 — žádné slepování

&--featured ani &__body nejsou platné CSS. Selektor musíš napsat celý (&.card--featured, .card__body), takže BEM zápisy z Lessu se sem nepřepíšou jeden na jeden.

Past 2 — specificita &

& nese specificitu jako :is() celého seznamu rodičů, tedy nejsilnějšího z nich. V .btn, #hero { & span { … } } má vnořené pravidlo specificitu #hero — u preprocesoru by vznikly dva selektory, každý s vlastní specificitou.

CSS Nesting — klíčové vzory

/* 1. Základní nesting — & je odkaz na rodičovský selektor */
.nav {
  display: flex;
  gap: var(--base-2);

  & .nav__item { list-style: none; }   /* potomek */
  & .nav__link { text-decoration: none; color: var(--text-primary); }
  & .nav__link:hover { color: var(--text-brand-primary); } /* pseudo-třída */
}

/* 2. Modifier & state vše v jednom bloku */
.btn {
  padding: var(--base-h) var(--base-3);
  background: var(--surface-brand-primary-strong);

  &:hover        { filter: brightness(1.1); }
  &:disabled     { opacity: 0.4; cursor: not-allowed; }
  &:focus-visible { outline: 2px solid currentColor; outline-offset: 3px; }
  &.btn--ghost   { background: transparent; border: 1px solid currentColor; }
}

/* 3. @media vnořené přímo v pravidle */
.hero {
  font-size: var(--font-size-xxl);
  flex-direction: row;

  @media (max-width: 600px) {
    font-size: var(--font-size-xl);   /* bez opakování selektoru */
    flex-direction: column;
  }
}

/* 4. & je u potomka nepovinný — implicitně se doplní */
.card {
  border-radius: var(--radius);

  .card__title { font-weight: 600; }  /* implicitní & před potomkem */
  .card__body  { color: var(--text-secondary); }
}
